Git

  • git init — создает новый локальный репозиторий в текущей папке
  • git clone — копирует удаленный репозиторий на локальный компьютер
  • git add — добавляет изменения в файлах в область подготовки к коммиту
  • git commit — сохраняет проиндексированные изменения в истории репозитория
  • git push — отправляет локальные коммиты в удаленный репозиторий на GitHub
  • git pull — загружает изменения из удаленного репозитория и объединяет их с локальными
  • git status — показывает текущее состояние рабочей директории и индекса
  • git branch — показывает список веток или создает новую ветку
  • git checkout — переключает на другую ветку или коммит
  • git log — показывает историю коммитов
